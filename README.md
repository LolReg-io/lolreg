# LOLREG

### Summary

A curated collection of Windows Registry keys used for persistence, privilege escalation, and defense evasion.

LOLREG is accessible [HERE](https://lolreg.io)

### How to contribute 

Check the dedicated documentation page if you want to contribute : [CONTRIBUTING](https://github.com/LolReg-io/lolreg/blob/main/CONTRIBUTING.md)

### Build website locally

``` 
npm install
``` 

Build LOLREG website :

```
npm run build
``` 

Run a preview of the website locally :

``` 
npm run preview
```
